🔍 New Research: HP-C4D
A Fast Camera and 4D Radar Fusion Framework with Height Prediction For 3D Object Detection

We invite you to follow our recently proposed HP-C4D framework, which fuses images with 4D millimeter-wave radar for object detection. This work aims to address the challenges in accurately predicting bounding box height caused by the loss of height information during image perspective transformation and the inherent inaccuracies in height data from 4D radar point clouds.
